# 外语学习插件 · 使用说明书

给 AstrBot 加一套**外语学习**系统。支持 **英语 / 日语 / 韩语 / 泰语** 四种语言，
覆盖「词库管理 → 定时推送 → 群里答题 → 新闻采集」一整条学习链路，所有配置都在可视化面板里完成。

---

## 一、能做什么

| 功能 | 说明 |
|---|---|
| **词库 / 语法库** | 每种语言独立一套词库和语法库。支持增删改查、按**分组 / 标签 / 等级**筛选，并能把 Anki 牌组（`.apkg`/`.zip`/`.csv`/`.txt`/`.json`）直接导入进来、或导出备份。 |
| **定时推送** | 把单词或语法按规则推到群里：可设「每天固定时刻」或「每隔多久」，带随机浮动避免太死板；可以只推某个分组 / 标签 / 等级的内容。 |
| **群里答题** | 定时往群里发一道选择题，群友**直接点按钮**作答，时间一到自动出榜单 + 答案解析。 |
| **日语新闻** | 自动采集 NHK / Yahoo! Japan 的日语新闻，按设定时间推送到群。 |
| **命令自定义** | 触发词、要不要先 @ 机器人、要不要加命令前缀，全部可以在面板上改。 |
| **可视化面板** | 上面这些功能的所有配置，都在插件面板里用网页操作，不用碰代码。 |

---

## 二、安装

1. 把本插件目录（名为 `astrbot-plugin-lang-learning`）放进 AstrBot 的 `data/plugins/` 目录下。
   > 放好后完整路径形如：`data/plugins/astrbot-plugin-lang-learning/`
2. 重启 AstrBot，或在面板里重载插件即可生效。
3. **不需要安装任何第三方依赖**。官方 QQ 机器人所需的 `botpy` 由 AstrBot 的 QQ 官方平台适配器自带。

---

## 三、快速上手（三步）

第一次用，照着做就能跑起来：

1. **打开面板** → 顶部选一门语言（英语 / 日语 / 韩语 / 泰语）。
2. **先有词**：在「单词管理」里手动加几条，或点「导入文件 / ZIP」把 Anki 牌组导进来。
   > 没有词库，推送和答题都没内容可出。
3. **建一条规则**：去「单词/语法推送」建一条推送规则，或去「答题推送」建一条答题规则，
   然后在 QQ 群里发对应的命令（见下一节）试一下。

---

## 四、面板说明

面板顶部是一排**语言**切换，下面是各功能页签。所有改动即时保存。

### 单词管理 / 语法管理
- 搜索框可按 单词 / 读音 / 释义 / 例句 / 标签 / 分组 模糊搜索。
- 右侧下拉可按 **分组 / 标签 / 等级** 过滤，并能按「最近修改 / 最近添加 / 字词」排序。
- 「+ 新增单词」单条录入；「导入文件 / ZIP」支持 Anki / CSV / TXT / JSON 批量导入。
- 「导出」可把当前词库打包带走（备份或换机器用）。

### 题库管理
- 这里是**答题**用的题库（与上面的单词库分开）。
- 支持导入 / 导出题库包（`.zip` / `.json`），也能在面板上自建题目。
- 可维护一个「排除名单」（某些题不进随机池）。

### 答题推送
- 新建一条答题规则：设定**出题方式**（随机 / 顺序）、**等级范围**、**题型**、**答题窗口时长**等。
- 「立即出题」按钮可随时手动出一道题到群里测试。
- 规则可设成**定时自动出题**（每天 / 每隔多久）。

### 单词 / 语法推送
- 新建一条推送规则：选语言 + 类型（单词 / 语法），选**投递到哪台机器人、哪个群**。
- 排期可选「每天多个时刻」或「按间隔」，并可加随机浮动。
- 可设过滤条件：只推某个分组 / 标签 / 等级。

### 新闻推送
- 启用 NHK / Yahoo! Japan 新闻源，设定定时推送时间和目标群。

### 命令配置
- 集中管理所有**触发词**：给每种语言改「单词 / 语法 / 答题 / 学习菜单」的叫法。
- 设置命令要不要**先 @ 机器人**，以及是否加**命令前缀**（如 `/`）。

## 五、在 QQ 群里怎么用

> ⚠️ 所有命令**只能在群里用**（推送、答题、菜单都是群功能）。私聊机器人发命令会提示你去群里。

### 默认命令

假设选的是日语，默认触发词是：

| 你想干嘛 | 在群里发 |
|---|---|
| 推一条日语单词 | `日语单词` |
| 推一条日语语法 | `日语语法` |
| 出一道日语题 | `日语答题` |
| 打开这门语言的学习菜单 | `日语学习菜单` |
| 打开这门语言的菜单（简写） | `日语菜单` |

英语 / 韩语 / 泰语同理，把「日语」换成对应语言名即可。
触发词可以在「命令配置」页随意改（比如改成 `jp vocab` 之类）。

### 答题怎么玩

1. 群里发 `日语答题`（或定时规则自动出题）。
2. 机器人发一道选择题，**群友直接点消息上的 A / B / C / D 按钮**作答（官方 QQ 机器人原生支持，不用打字）。
3. 答题窗口结束，自动出**排行榜 + 每题正确答案和解析**。

> 想让谁都能触发：群里任何人发命令都有效。要限制权限可在插件代码里加管理员判断。

### 答题命令可带参数

出题时想临时限定范围，命令后面加参数即可（任意组合、顺序随意、全都能省略）：

```
日语答题 level=1                # 只出 N1 难度（也认 level=N1；范围写 level=1-3）
日语答题 type=语法              # 只出语法题（多个题型用逗号：type=语法,听力）
日语答题 mode=宽松              # 抽不到就逐级放宽限制（默认「严谨」）
日语答题 window=3m              # 答题窗口 3 分钟（裸数字按秒：window=180）
日语答题 level=1 type=语法 mode=宽松 window=3m
```

- 等级只认 JLPT 的 **N5 ~ N1**。
- `type` 里出现的题型，必须是对应的题库里真实存在的（你自己导入的听力题也能点名）。
- 参数写错会当场回一句提示，**不会 silently 用旧配置**——照着提示改就行。

## 六、数据备份与迁移

| 内容 | 怎么备份 / 还原 |
|---|---|
| 词库 / 语法库 | 面板「导出」打包；还原时「导入文件 / ZIP」。 |
| 答题题库 | 「题库管理」里导出 `.zip` / `.json`；换机器用「导入题库包」。 |
| 推送 / 答题规则、命令配置 | 随插件数据一起保存，复制整个数据文件夹即整体迁移。 |

数据保存在 AstrBot 的插件数据目录（`data/plugin_data/astrbot_plugin_lang_learning/`），
**更新插件时不会被清掉**。要整体备份，直接复制这个文件夹即可。

## 七、常见问题

**Q：官方 QQ 机器人发出来的消息是卡片 / 带按钮，正常吗？**
正常。官方 QQ 机器人天生以 markdown 卡片形式发送，选择题的按钮就挂在卡片上，点一下即作答。

**Q：在群里发命令没反应？**
依次检查：① 面板顶部「模块开关」是否开着；② 对应语言的规则是否**启用**；
③ 本群有没有可用的发送机器人（去「命令配置」把某台机器人设成「任何群可用」或把本群勾上）；
④ 如果设了「要先 @ 机器人」，记得先 @ 再发命令。

**Q：答题时群友的答案没收到的样子？**
窗口内直接点消息上的 **A / B / C / D** 按钮即可，机器人会默默记下，不用额外回复。

**Q：含听力的题会怎样？**
听力题的音频会作为**单独一条语音**发送（它和文字是两种不同的消息类型），文字正文始终只有一条。

**Q：升级插件会弄丢数据吗？**
不会。词库、规则都在上面的数据目录里，覆盖插件目录后重启即可，数据原样保留。

## 八、更新与卸载

- **更新**：把新版插件目录覆盖到 `data/plugins/astrbot-plugin-lang-learning/`，重启或重载插件。
- **卸载**：删掉该插件目录即可；如想连数据一起清，再删除 `data/plugin_data/astrbot_plugin_lang_learning/`。
