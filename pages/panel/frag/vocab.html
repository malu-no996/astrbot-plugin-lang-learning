支持哪些文件

  • .apkg —— Anki 卡包（自动读里面的 SQLite 笔记表）
  • .zip —— 包里可以有 csv / txt / json / 甚至多个 .apkg
  • .csv / .txt —— 制表符或逗号分隔，有表头就按表头映射（中英文列名都认）
  • .json —— {"items":[{...}]} 或数组

导出是制表符分隔的文本：term / reading / meaning / example / example_trans / tags / level / group， Anki 的「文件导入」选它就完事，再导回来也会回到原来的分组。

分组：每次导入的条目会自动归到一个分组，名字默认取文件名 （xxxN1单词.apkg → 分组「xxxN1单词」；一个 zip 里多份词表时各自用自己的文件名）， 也可以在下面的预览框里改。分组能用来筛选、整组改名 / 删除，也能让 QQ 推送「只从某几个分组抽词」。
