导入题库包

支持 .zip（里面可以有多个 .json 题库包）或单个 .json。 包的 id 取自 _meta.id，没有就用文件名；分组取自 _meta.group； 语言取自 _meta.lang，没写就落成当前语言（{{ lsLangLabel() }}）。

合并导入：保留包里原有的题，按题目 id 覆盖同名题 —— 反复导同一份不会翻倍，推荐。
替换导入：整个包换掉，原先那个包里的题会丢。

批量导入题目

贴一个 JSON 数组（或含 items 数组的对象），每题字段： level type question options（数组） answer（必须是某个选项原文）explanation topic difficulty group（分组，留空算「自建」）audio（听力音频 URL，可选）。 这些题会落进当前语言（{{ lsLangLabel() }}）的「自建」题库包，想成包搬走就用上面的「导出 zip」。
