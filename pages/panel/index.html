「答题」可以在命令后面带参数，临时改这一次的出题范围（不动规则本身）， 以日语为例：日语答题 level=1 type=语法 mode=宽松 window=3m —— level 等级（1=N1，可写 1-3 范围）； type 题型（语法 / 听力 / 词汇 / 汉字 / 读解，多个用逗号）； mode 严谨（默认，抽不到就说没有）/ 宽松（抽不到就逐级放宽到能出题）； window 答题窗口（3m / 180，裸数字按秒）。 参数都能省，键名也认中文（等级 / 题型 / 模式 / 时间）。
